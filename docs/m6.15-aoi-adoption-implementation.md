## 3. Observation coverage is not AOI area

| Quantity | Value / denominator |
|---|---|
| Full continuous polygon | **206.150650904 km²** |
| Delivered continuous support | **130.641632265 km²**, AOI ∩ common local RTC window |
| Delivered fraction | **0.633719232474** of the whole polygon (63.3719232%) |
| Undelivered / unobserved | **75.509018639 km²**, 36.6280768% |
| Covered pixel centers | **1,306,418**, rasterized against the polygon, not its envelope |
| Joint valid centers | **1,306,418**, all pre/post VV/VH bands valid |
| Per-band invalid covered centers | **0** in each of the four band/date combinations |
| Valid fraction of delivered centers | **1.000000**; emphatically not whole-AOI coverage |
| Valid pixel-area estimate | **130.6418 km²**, count × 100 m² |
| Valid pixel-area / full AOI area | **0.633720046128**, explicitly a rasterization estimate |
| Existing raster grid | EPSG:32645, 10 m, 3313×4961; bounds `308770,3080970,341900,3130580` |

Joint validity requires GDAL mask valid **and** not declared nodata (`-32768`)
**and** finite **and** strictly positive linear SAR power, across every source
and band. Zero, negative, NaN and infinity are not dark-water evidence. The
module rejects incompatible grids, geographic/non-metre rasters, URLs and VRT
sources; no resampling occurs. Pixel-center rasterization uses `all_touched=false`.
Pixel-area estimates differ slightly from continuous geometric intersection at
boundaries and must never silently replace geometric coverage.

The sidecar includes geometric delivered and unobserved footprint geometries,
including EPSG:4326 map-ready versions. These identify delivery support, **not**
a valid-pixel mask; interior invalid observations must still be masked. Here the
four covered bands have no invalid pixels. The map shades undelivered area as
unknown and labels the entire AOI outline context-only. No result layer is shown
while M6.3 is stale.
